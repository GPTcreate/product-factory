# Product Factory — 무료 주소 우선 / 도메인 구매 보류 정책

적용일: 2026-10-19  
대상: 52개 린프로젝트의 신규 제품 및 최대 72회 서비스 실험  
성격: 운영 가이드. 이 문서만으로 실제 도메인, 배포, DB 및 광고 설정을 변경하지 않는다.

## 기본 정책

1. **도메인 구매는 출시 조건이 아니다.** 신규 MVP는 `*.pages.dev`, `*.vercel.app` 등 호스팅 사업자의 무료 공개 HTTPS 주소를 기본으로 사용한다. 서비스별 맞춤 도메인은 비용 승인 전까지 구입하지 않는다.
2. **기존 도메인 보존.** P001 IPOScore의 `iposcore.kr`을 임의로 해지·전환하지 않는다. 다른 서비스도 기존 URL을 무단 변경하지 않는다.
3. **무료 티어 우선.** 개발·배포·운영은 무료 제공량 안에서 설계한다. 도메인 구입/갱신, 유료 플랜, 유료 API, 초과 사용요금 등 금전 지출은 사전 승인이 필요하다.
4. **출시와 광고 심사를 분리.** 실제 서비스 주소에서 기능·데이터 갱신·측정이 확인되면 MVP 출시를 평가할 수 있다. AdSense 승인과 수익 수집은 별도의 확인 조건이다.
5. **성과 없는 선투자 금지.** 트래픽·재방문·핵심 사용자 행동·운영 안정성이 확인되기 전에는 도메인 비용을 지출하지 않는다.

## Factory 등록 방법

Factory의 `Domain`은 구매한 도메인 여부와 무관한 **운영 호스트명**(프로토콜/경로 제외)이다. 무료 주소를 그대로 입력한다.

| 필드 | 무료 서비스 주소 예시 | 주의 |
| --- | --- | --- |
| `domain` | `badastatus.pages.dev` | 실제 배포가 확인된 호스트만 입력 |
| `website_url` | `https://badastatus.pages.dev` | 실제 접속과 핵심 기능을 확인 |
| `deploy_url` | `https://badastatus.pages.dev` | 실제 배포 주소 |
| `status` | `BUILD` 또는 `LIVE` | 검증 전에는 임의로 LIVE 처리 금지 |
| `adsense_enabled` | `false` | 승인 및 검증된 귀속 전에는 연결하지 않음 |
| `adsense_mapping_key` | 비움 | 실제 AdSense의 verified site domain만 사용 |

이 표는 **입력 예시**로서 `badastatus.pages.dev`의 최신 배포 성공을 인증하는 기록이 아니다. Cloudflare에 프로젝트가 존재하는 것과 사이트가 동작하는 것은 별도 검증한다. GA4/GSC/Bing 속성도 실제 운영 주소를 기준으로 따로 연결·검증한다.

## 도메인 구매 검토 게이트

첫 검증 운영 기간은 기본 **4주**로 제안하되, 기간만 지나면 자동 구입하지 않는다. 각 제품의 `HOLD/KILL/IMPROVE/SCALE` 검토 시 아래 근거를 남긴다.

- 실제 사용자 핵심 행동과 자동 데이터 갱신의 안정성
- 실제 측정된 검색 노출·유입·재방문·핵심 이벤트. `미측정`은 `0`과 구분
- 원천 데이터 사용 가능성과 수집 중단 위험, 유지보수 비용
- 맞춤 도메인이 필요한 구체적 이유(브랜드, 신뢰, 수익화, 서비스 확장)
- 구매 및 연간 갱신 예산, 다른 프로젝트와 비교한 우선순위
- 사용자 비용 승인 여부

충분한 근거가 없거나 예산이 없으면 **무료 주소를 유지**한다. 특정 트래픽 임계치만으로 자동 결제하지 않는다.

## AdSense 및 공통 도메인 관련 제한

- 무료 배포 주소의 AdSense 등록·심사·수익화 가능 여부를 보장하지 않는다. 실제 Google AdSense 계정의 사이트 검증·심사·보고서를 확인해야 한다.
- 광고 심사 중이거나 미연결이면 `Not Connected/Pending`으로 표시한다. 수익 `0` 확정으로 간주하지 않는다.
- 현 Factory는 `OWNED_SITE_DOMAIN_NAME` 하나를 한 제품에 귀속하며, 같은 검증된 사이트 도메인의 여러 제품 광고 수익을 자동 분리하지 않는다.
- 공통 브랜드 도메인과 여러 서브도메인 구성은 향후 선택지일 뿐이며 **지금 구매하지 않는다**. 추후 AdSense의 사이트 검증 단위와 제품별 귀속을 먼저 설계한다.

## 향후 승인된 도메인으로 이동할 때

기존 URL·검색 데이터와 수익 귀속을 보존하고, 가능한 경우 영구 리다이렉트·canonical·sitemap·GSC 속성 변경 및 GA4 연속성을 준비한다. Factory의 `domain`/`website_url`/provider 식별자를 새 운영 주소로 변경하기 전에 운영 영향과 복구 절차를 검토한다. 기존 AdSense 수익 이력이 있는 매핑은 DB 보호 규칙이 있으므로 임의 수정·삭제하지 않는다.

## 적용 상태

본 문서와 제품 제작 가이드·준비 템플릿·README에 정책을 반영한다. 제품의 실제 도메인·운영 DB·광고·호스팅 요금제는 본 기록 때문에 변경되지 않는다.
