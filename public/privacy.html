개인정보처리방침

Product Factory는 운영자 본인의 웹사이트를 관리하기 위한 개인용 도구입니다. 일반 사용자에게 Google 계정 연결이나 가입을 제공하지 않습니다.

접근하는 데이터와 목적

Google OAuth 동의를 통해 Analytics의 방문·페이지·유입 통계, Search Console의 사이트·검색어·검색 성과 보고서, AdSense의 광고 성과 보고서에 읽기 전용으로 접근합니다. AdSense 데이터는 연결이 설정된 경우에만 수집합니다. 이 데이터는 운영자 자신의 웹사이트 성과 분석, 대시보드 표시, 수집 상태 점검에 사용됩니다.

저장과 보호

조회한 보고서와 수집 이력은 기존 Supabase 프로젝트에 저장합니다. Google 인증 정보는 서버의 보호된 Secret 저장소에 보관하고 공개 페이지에 제공하지 않습니다. 대시보드는 허용된 운영자 계정과 다중 인증으로 접근을 제한하며 데이터베이스 접근 정책을 적용합니다. 웹 화면은 Cloudflare Pages에서 제공됩니다.

공유와 사용 제한

Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. 데이터 제공은 Google API 호출, Supabase를 통한 저장·처리 등 도구 운영에 필요한 서비스 이용으로 한정합니다. Google 데이터를 범용 AI·머신러닝 모델의 학습에 사용하지 않습니다.

Product Factory의 Google API 정보 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

보관·삭제와 연결 해제

운영자는 필요한 보고서를 보관하고 자신의 데이터베이스에서 삭제할 수 있습니다. 수집 로그는 운영 정리 정책에 따라 삭제될 수 있습니다. Google 계정의 서드 파티 연결에서 권한을 취소하면 이후 Google 데이터 수집이 중단됩니다. 권한 취소만으로 이미 저장한 보고서가 자동 삭제되지는 않으므로 운영자가 별도로 삭제합니다.

문의와 변경

이 도구의 유일한 사용자인 운영자가 직접 데이터 열람·삭제와 인증 관리를 수행합니다. 연결 관련 문의 주소는 Google 동의 화면의 사용자 지원 이메일에서 확인할 수 있습니다. 데이터 이용 방식이 바뀌면 이 안내도 갱신합니다.
